Features

Everything a scraping pipeline needs

From single-URL quick grabs to async batch jobs across hundreds of pages — with AI extraction that reads the page like a human.

🧠
Schema-driven AI extraction

Describe what you want in plain English. LangChain + GPT-4o-mini extracts structured fields — strings, numbers, booleans, lists — from any page layout.

⚡
Two scraping engines

httpx for fast static pages. Playwright headless browser for JavaScript-rendered SPAs, infinite scroll, and login-gated content.

📋
Async batch jobs

Submit up to 100 URLs in one call. Jobs run concurrently in the background with live progress tracking and per-URL error handling.

🔄
Auto pagination

Enable follow_pagination and the engine detects Next links automatically, following them across up to 50 pages.

📦
Export to JSON / CSV / Excel

One API call downloads your results as a formatted file. Excel exports include styled headers, auto-fit columns, and flat nested objects.

🔁
Retry + polite delays

Automatic exponential backoff on failures. Configurable per-request delays to respect robots.txt and avoid rate limiting.

🗄️
Persistent job store

Every scrape and result is stored in SQLite (dev) or PostgreSQL (prod). Query history, re-export, or build dashboards on top of your data.

🐳
One-command deploy

docker-compose up spins up the API, PostgreSQL, and Redis together. Production-ready with 4 Uvicorn workers.

📖
Interactive Swagger docs

Auto-generated docs at /docs. Every endpoint, schema, and response type is documented and testable in the browser.

How it works

From URL to structured data in seconds

Three steps. One API call. Works on any website.

01
Define your schema

Describe the fields you want extracted in plain English. Field names, types, and a one-line description is all the AI needs.

02
Point at a URL

Send a POST request with your URL and schema. Choose httpx for speed or Playwright if the site uses JavaScript rendering.

03
AI extracts + returns JSON

LangChain cleans the HTML, sends it to GPT-4o-mini with your schema, and returns a validated JSON object — every time.

04
Export your data

Download results as JSON, CSV, or styled Excel. For batch jobs, poll the job endpoint for progress and pick up results when complete.

# 1. Define what to extract
POST /api/v1/scrape/

{
  "url": "https://example.com/product",
  "schema_def": {
    "fields": [
      {
        "name":        "product_name",
        "description": "Full product title",
        "field_type":  "string"
      },
      {
        "name":        "price",
        "description": "Price with currency",
        "field_type":  "string"
      },
      {
        "name":        "features",
        "description": "List of key features",
        "field_type":  "list"
      }
    ]
  }
}

# Response →
{
  "extracted_data": {
    "product_name": "Super Widget Pro",
    "price":        "$49.99",
    "features":    ["Wireless", "USB-C", "Waterproof"]
  }
}
# 2. Scrape 100 URLs concurrently
POST /api/v1/scrape/batch

{
  "urls": [
    "https://site.com/page/1",
    "https://site.com/page/2",
    ... up to 100 URLs ...
  ],
  "schema_def": { /* same as above */ },
  "options": {
    "use_playwright":    false,
    "follow_pagination": true,
    "max_pages":         5,
    "delay_seconds":     1.0
  }
}

# Returns immediately with job ID
{ "job_id": "a3f2c1...", "message": "Queued 50 URLs" }

# Poll for progress
GET /api/v1/jobs/a3f2c1...
{ "status": "running", "progress": 64 }
# 3. Export completed job results

# As CSV
POST /api/v1/jobs/a3f2c1.../export
{ "job_id": "a3f2c1...", "format": "csv" }

# As Excel

# As JSON
{ "format": "json" }
→ Downloads scrape_a3f2c1.json

API Reference

All endpoints

Full interactive docs available at /docs when running locally.

POST /api/v1/scrape/ Single URL scrape + AI extract
Scrape a single URL and optionally extract structured data. Returns synchronously.

url schema_def options.use_playwright options.wait_for_selector options.custom_headers
POST /api/v1/scrape/batch Batch scrape (async job)
Submit up to 100 URLs for concurrent async scraping. Returns a job_id immediately.

urls[] schema_def options.follow_pagination options.max_pages options.delay_seconds
GET /api/v1/scrape/quick Fast rule-based scrape (no AI)
Scrape and extract common fields (title, links, images, headings, Open Graph) without an API key. No schema needed.

url (query param)
POST /api/v1/extract/ Extract from raw text or HTML
Already have the HTML? Skip scraping and run AI extraction directly on any content string.

content schema_def source_url (optional)
GET /api/v1/jobs/{id} Get job status + progress
Poll a batch job for status (pending → running → completed), progress percentage, result count, and timing.
GET /api/v1/jobs/{id}/results Paginated job results
Retrieve extracted results for a completed job. Supports limit and offset for pagination.
POST /api/v1/jobs/{id}/export Download results as file
Export all job results to a downloadable file. Supported formats: json, csv, excel.

job_id format
DEL /api/v1/jobs/{id} Delete job and results
Permanently delete a job and all of its scraped results from the database.
Get started

Up and running in 3 minutes

LOCAL DEVELOPMENT
$ git clone github.com/you/ai-web-scraper
$ cd ai-web-scraper
$ pip install -r requirements.txt
$ playwright install chromium
$ cp .env.example .env
# Add OPENAI_API_KEY to .env
$ uvicorn app.main:app --reload
# → http://localhost:8000/docs
DOCKER DEPLOY
$ export OPENAI_API_KEY=sk-...

# Starts API + PostgreSQL + Redis
$ docker-compose up -d

# Check it's running
$ curl localhost:8000/health
{ "status": "ok" }

# View live logs
$ docker-compose logs -f api
RUN TESTS
